## Supplement — Remotion lab: thumbnails + dataset `frames` (`LOG:`)

- **Data hook:** [`useRemotionSandboxPreviewData`](src/components/remotion/remotion-sandbox-preview-data.ts) — single fetch + [`mergeSandboxDataset`](src/components/remotion/remotion-sandbox-dataset.ts); consumed by [`RemotionPreview`](src/components/remotion/remotion-preview.tsx).
- **Player + stills:** [`RemotionPreview`](src/components/remotion/remotion-preview.tsx) renders `@remotion/player` `Player` and one or more `Thumbnail` components with the same `FixturaTemplateScene`, `inputProps`, 1080×1350, 30 fps, and [`data-remotion-preview-root`](src/components/remotion/remotion-preview.css) scope.
- **Frame constant:** [`REMOTION_SANDBOX_PREVIEW_THUMBNAIL_FRAME`](src/components/remotion/remotion-sandbox-options.ts) (= 10) used when dummy JSON has no usable top-level `frames` array.
- **Dataset frames:** [`getSandboxThumbnailFramesFromData`](src/components/remotion/remotion-sandbox-dataset.ts) reads top-level **`frames`** (array of integers) from Fixtura dummy data (e.g. [`Cricket_Ladder.json`](public/dummyAssetData/Cricket/Cricket_Ladder.json)); if missing/empty/non-integer, falls back to `[REMOTION_SANDBOX_PREVIEW_THUMBNAIL_FRAME]`. Each value is clamped to `durationInFrames - 1` with an orange warning when any clamp applies. Lab shows a wrapping row of thumbnails with per-frame labels and a `Frames: […]` line when using dataset frames.
